# data-annotation-portfolio
📊 Data Annotation Portfolio – Image Annotation & Segmentation

Welcome to my Data Annotation Portfolio!

This repository showcases my practical experience and learning in Image Annotation, Object Detection, and Image Segmentation using Roboflow.

I created this project to demonstrate my understanding of data annotation techniques and my ability to prepare quality-labeled datasets for machine learning and computer vision applications.

🎯 Project Objective

The main objective of this project is to practise image annotation and create a structured, well-organized dataset that can be used for training computer vision models.

🛠️ Tools & Technologies

- Roboflow: Image annotation and dataset management.
- YOLO: Object detection dataset format.
- GitHub: Project documentation and portfolio management.

🔍 Project Workflow

1. Collected and organized the original image dataset.
2. Uploaded images to Roboflow.
3. Identified objects in the images.
4. Applied annotations to the images.
5. Reviewed annotation placement and label consistency.
6. Exported the annotated dataset.
7. Organized the project files and uploaded them to GitHub.
